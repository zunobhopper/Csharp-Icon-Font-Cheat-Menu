## 📦 ImGui Icon Menu Template for C# (with Clickable Transparent Overlay)

Hey there!

This template was created to help you **easily add icons** to your **ImGui menus** using a **clickable transparent overlay** in **C#** — something that's surprisingly under-documented and tricky to implement. After spending a lot of time figuring it out, I decided to release the **full source code** to make the process easier for others.

Whether you're building a cheat menu, a game UI, or experimenting with overlays, this is a great place to start.

### 📝 Features

* ✔️ Fully working **icon rendering** in ImGui (via font atlas)
* ✔️ **Clickable transparent overlay** in C#
* ✔️ Pre-styled and tabbed menu system
* ✔️ Easy to extend and customize
* ✔️ Ideal for **cheat menus** (CS2-focused but adaptable)

### 💡 Developer Notes

While everything works great out of the box, the structure of this project is a bit unique — so **copy-pasting it into another project might lead to issues**. Instead, I strongly recommend that you **build your cheat features directly inside this project**. It’s much more stable and consistent that way.

Use this as a solid foundation and customize it to fit your own use case.
