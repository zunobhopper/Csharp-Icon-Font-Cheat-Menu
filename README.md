## 📦 ImGui Icon Menu Template for C# (with Clickable Transparent Overlay)

Hey there!

This template is built to help you **use icons in your ImGui menu** within a **clickable transparent overlay** in **C#** — something that's notoriously difficult and rarely documented. After spending way too much time figuring it out myself, I decided to share the full **source code** to make it easier for others.

Whether you're building a cheat menu, custom game UI, or just experimenting with overlays — this gives you a solid starting point.

### 🎥 Tutorial

If you're new to this or want a full walkthrough, check out the [video tutorial here](https://youtu.be/mINcRSDJqFc). It covers everything step-by-step, even for complete beginners.
